# [BUG][Validation] Hệ thống không hiển thị thông báo lỗi khi nhập chữ cái hoặc ký tự đặc biệt vào Second Number

## Found by Test Case
- [TC-INPUT-010](../test-cases/input/TC-INPUT-010.md)
- [TC-VALIDATION-003](../test-cases/validation/TC-VALIDATION-003.md)

## Requirement liên quan
- FR-INPUT-10
- FR-VALIDATION-03

## Severity / Priority
Major / P1

## Environment
- **Browser**: Chromium (Playwright) / Google Chrome
- **OS**: Windows 11
- **URL**: https://testsheepnz.github.io/BasicCalculator.html?build=1
- **Build Version**: Build 1

## Steps to reproduce
1. Truy cập vào trang web `https://testsheepnz.github.io/BasicCalculator.html?build=1`
2. Nhập số hợp lệ vào ô **First number** (ví dụ: `10`)
3. Nhập ký tự đặc biệt (ví dụ: `@#$`) hoặc chữ cái (ví dụ: `abc`) vào ô **Second number** (`id="number2Field"`)
4. Chọn Operation = **Add**
5. Nhấn nút **Calculate** (`id="calculateButton"`)
6. Quan sát thông báo lỗi tại nhãn **errorMsgField** (`id="errorMsgField"`) và giá trị ô **Answer** (`id="numberAnswerField"`)

## Expected result
- Hệ thống phải kiểm tra tính hợp lệ của dữ liệu đầu vào ô Second number.
- Hiển thị thông báo lỗi: `Number 2 is not a number` tại `id="errorMsgField"`.
- Ô **Answer** không được hiển thị kết quả tính toán hợp lệ.

## Actual result
- Hệ thống không hiển thị bất kỳ thông báo lỗi nào tại `id="errorMsgField"` (nhãn rỗng `""`).
- Kiểm thử tự động Playwright bị fail với lỗi:
  ```text
  Error: expect(locator).toHaveText(expected) failed
  Locator: locator('#errorMsgField')
  Expected: "Number 2 is not a number"
  Received: ""
  ```
