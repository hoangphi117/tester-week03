## Steps to reproduce
1. Truy cập trang web `https://testsheepnz.github.io/BasicCalculator.html?build=2`
2. Nhập số vào ô **First number**: `15`
3. Nhập số vào ô **Second number**: `25`
4. Chọn Operation = **Add**
5. Nhấn nút **Calculate** (`id="calculateButton"`)
6. Quan sát kết quả tại ô **Answer**: hiển thị `1525` (thực hiện phép nối chuỗi String Concatenation thay vì phép cộng số học 15 + 25 = 40)
7. Đổi Operation sang **Concatenate**
8. Nhấn nút **Calculate**
9. Quan sát kết quả tại ô **Answer**: hiển thị `40` (thực hiện phép cộng số học thay vì phép nối chuỗi `1525`)

## Expected result
- Khi chọn **Add**: Hệ thống phải thực hiện phép toán cộng số học `15 + 25 = 40`, kiểm tra hợp lệ dữ liệu số học.
- Khi chọn **Concatenate**: Hệ thống phải thực hiện nối chuỗi `15` và `25` thành `1525`.

## Actual result
- Phép toán **Add** và **Concatenate** bị tráo đổi hoàn toàn (Inverted / Swapped Operations):
  - Chọn **Add**: Hệ thống thực thi nối chuỗi (`answer = num1 + num2`), bỏ qua kiểm tra số học `isNumber = false`.
  - Chọn **Concatenate**: Hệ thống thực thi phép cộng (`answer = +num1 + +num2`), ép buộc kiểm tra số học `isNumber = true`.
- Đoạn mã lỗi trong source của Build 2:
  ```javascript
  // Applying build 2 oddball
  if (selectedBuild == 2) {
    if (selection == 0) { // 0 là Add
      selection = 4;     // Đổi thành 4 (Concatenate)
      isNumber = false;
    } else if (selection == 4) { // 4 là Concatenate
      selection = 0;     // Đổi thành 0 (Add)
      isNumber = true;
    }
  }
  ```
