# [BUG][Calculate] Phép chia hai số nguyên trả về kết quả làm tròn thay vì số thập phân

## Environment
- **Browser**: Chromium (Playwright) / Google Chrome
- **OS**: Windows 11

- **Build Version**: Build 4

## Steps to reproduce
1. Truy cập vào trang web `https://testsheepnz.github.io/BasicCalculator.html?build=4`
2. Nhập `5` vào ô **First number** (`id="number1Field"`)
3. Nhập `2` vào ô **Second number** (`id="number2Field"`)
4. Chọn Operation = **Divide** (`id="selectOperationDropdown"`)
5. Nhấn nút **Calculate** (`id="calculateButton"`)
6. Quan sát kết quả hiển thị tại ô **Answer** (`id="numberAnswerField"`)

## Expected result
- Phép tính `5 / 2` phải trả về kết quả số thập phân chính xác: `2.5` tại ô **Answer**.

## Actual result
- Ô **Answer** hiển thị kết quả làm tròn thành số nguyên là `2` (bị mất phần thập phân `.5`).
- Kiểm thử tự động Playwright bị fail với lỗi:
  ```text
  Error: expect(locator).toHaveValue(expected) failed
  Locator: locator('#numberAnswerField')
  Expected: "2.5"
  Received: "2"
  ```
