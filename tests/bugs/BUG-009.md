## Steps to reproduce
1. Truy cập vào trang web `https://testsheepnz.github.io/BasicCalculator.html?build=4`
2. Nhập `1` vào ô **First number** (`id="number1Field"`)
3. Nhập `3` vào ô **Second number** (`id="number2Field"`)
4. Chọn Operation = **Divide** (`id="selectOperationDropdown"`)
5. Nhấn nút **Calculate** (`id="calculateButton"`)
6. Quan sát kết quả hiển thị tại ô **Answer** (`id="numberAnswerField"`)

## Expected result
- Ô **Answer** phải hiển thị kết quả dạng số thập phân tuần hoàn có độ chính xác cao: `0.3333333333333333`.

## Actual result
- Ô **Answer** hiển thị kết quả là `0` (phần thập phân bị cắt hoàn toàn do checkbox Integers only bị hardcode bật).
- Kiểm thử tự động Playwright bị fail với lỗi:
  ```text
  Error: expect(locator).toHaveValue(expected) failed
  Locator: locator('#numberAnswerField')
  Expected: "0.3333333333333333"
  Received: "0"
  ```
