# [BUG][Validation] Hệ thống không hiển thị thông báo lỗi khi nhập chữ cái hoặc ký tự đặc biệt vào First Number

- **Browser**: Chromium (Playwright) / Google Chrome
- **OS**: Windows 11

## Steps to reproduce
1. Truy cập vào trang web `https://testsheepnz.github.io/BasicCalculator.html?build=1`
2. Nhập ký tự chữ cái (ví dụ: `abc`, `hello`) hoặc ký tự đặc biệt (ví dụ: `!@#$`) vào ô **First number** (`id="number1Field"`)
3. Nhập số hợp lệ vào ô **Second number** (ví dụ: `5` hoặc `10`)
4. Chọn Operation = **Add**
5. Nhấn nút **Calculate** (`id="calculateButton"`)
6. Quan sát thông báo lỗi tại nhãn **errorMsgField** (`id="errorMsgField"`) và giá trị ô **Answer** (`id="numberAnswerField"`)

## Expected result
- Hệ thống phải kiểm tra tính hợp lệ của dữ liệu đầu vào.
- Hiển thị thông báo lỗi rõ ràng: `Number 1 is not a number` tại `id="errorMsgField"`.
- Ô **Answer** không được hiển thị kết quả tính toán hợp lệ.

## Actual result
- Hệ thống không hiển thị bất kỳ thông báo lỗi nào tại `id="errorMsgField"` (nhãn rỗng `""`).
- Kiểm thử tự động Playwright bị fail với lỗi:
  ```text
  Error: expect(locator).toHaveText(expected) failed
  Locator: locator('#errorMsgField')
  Expected: "Number 1 is not a number"
  Received: ""
  ```
