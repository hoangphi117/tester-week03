# [BUG][Options] Checkbox 'Integers only' không bị ẩn khi chọn phép toán Concatenate

Major / P1

## Environment
- **Browser**: Chromium (Playwright) / Google Chrome
- **OS**: Windows 11
- **URL**: https://testsheepnz.github.io/BasicCalculator.html?build=3
- **Build Version**: Build 3

## Steps to reproduce
1. Truy cập vào trang web `https://testsheepnz.github.io/BasicCalculator.html?build=3`
2. Chọn phép toán (Operation) = **Concatenate** (`id="selectOperationDropdown"`)
3. Quan sát trạng thái hiển thị của ô chọn checkbox **Integers only** (`id="integerSelect"`)

## Expected result
- Khi chọn phép toán **Concatenate**, ô checkbox **Integers only** phải tự động ẩn đi (`toBeHidden()`) vì phép nối chuỗi không áp dụng quy tắc lọc số nguyên.

## Actual result
- Checkbox **Integers only** vẫn hiển thị rõ ràng trên giao diện, không bị ẩn đi.
- Kiểm thử tự động Playwright bị fail với lỗi:
  ```text
  Error: expect(locator).toBeHidden() failed
  Locator: locator('#integerSelect')
  Expected: hidden
  Received: visible
  ```

## Evidence
- Automated test fail tại: `src/tests/test-cases/OPT/options.spec.ts` (TC-OPTIONS-008) và `src/tests/test-cases/VAL/validation.spec.ts` (TC-VALIDATION-007)
- Video & screenshot ghi nhận trong thư mục: `test-results/`
